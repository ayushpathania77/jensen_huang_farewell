# Photograph catalogue

This album uses authentic photographs from Wikimedia Commons. Metadata was retrieved from the Commons API on 12 November 2026. The collection contains 23 distinct source photographs selected from 63 candidates; alternate crops, political-event photographs, and non-photographic media are excluded.

## Source archives

- [Wikimedia Commons: Jen-Hsun Huang by year](https://commons.wikimedia.org/wiki/Category:Jen-Hsun_Huang_by_year)
- [NVIDIA portrait archive](https://nvidianews.nvidia.com/multimedia/corporate/corporate-executives/jensen-huang-founder-president-and-ceo) was researched but no image was assumed reusable solely because it appeared in a press library. The 2014 portrait photograph is separately offered by NVIDIA on Commons under CC BY-SA 2.0.

## Reuse and modifications

Every photograph retains its individual source license. This collection does not assert ownership of the source photographs. Required creator attribution, source links, license links, and modification notices are supplied in the website’s photograph credits and below. Source photographs are resized and converted to WebP. The current Explore view and year quiz show the photographs in their source colors; thumbnails may crop the display, and the nine-piece puzzle uses a square crop divided into rearrangeable tiles. Adapted image treatments remain subject to the source photograph’s license. The NVIDIA 2014 portrait, including any cropped puzzle presentation, is offered under CC BY-SA 2.0. Any future downloadable composite must preserve its constituent images’ applicable licensing conditions.

Earlier screenshots directly inside `docs/screenshots/` document the preceding long-form design, which used a grayscale cover and collective portrait. Those treatments are historical previews, not a description of the current full-color interface. The current screenshots are in `docs/screenshots/interactive/`.

## Reproduction workflow

1. Run `scripts/collect_photos.ps1 -MetadataOnly` to retrieve source metadata with paced API requests.
2. Run `python scripts/curate_photos.py` to reproduce the reviewed selection and exclusion reasons.
3. Run `scripts/download_photos.ps1` to download the approved source images and create WebP variants. It publishes an initial three-photo manifest before continuing the remaining collection.
4. Use `scripts/collect_photos.py` with Pillow to regenerate the derivatives offline from the downloaded sources.

Downloaded source images are preserved in `assets/photo-originals/`, outside the public deployment folder. Only the optimized WebP variants in `public/photos/` are shipped. The redundant 2023 crop and its derivatives are retained only in the source archive.

The contact sheet (`photo-catalog-contact-sheet.jpg`) is a CC BY-SA 4.0 composite; creator credits and source licenses are listed above.

The machine-readable files `photo-catalog-candidates.json` and `photo-catalog-selected.json` preserve the source URLs, descriptions, author credits, source dates, licenses, image dimensions, and selection decisions. The frontend manifest is `src/data/photos.json`.

A source date or title is not an endorsement of the tribute. This is an independent community project.
